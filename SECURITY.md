# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's **Security → Report a vulnerability** (private advisory) on this
repository. Include the version, a description, and reproduction steps. You will get an answer within a few days.

## Supported versions

Only the latest release receives security fixes.
